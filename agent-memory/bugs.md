# 问题与风险

## 当前问题
- 暂无已知代码问题；本轮新增四项交易指标已按官方配置控件中的真实字段接入。
- 当前等待重新构建应用后，在应用自身 BrowserContext 下完成真实账号数据验收。

## 当前风险
- `compass.jinritemai.com` 页面内部接口不是公开稳定契约，路径、参数、动态安全机制或响应结构可能随官方升级变化。
- 动态安全参数与具体请求和会话相关，不得复制、缓存、固化或输出。
- 不同账号可能缺少部分指标；解析器和 UI 已允许字段为空并显示 `--`。
- 数据可见范围取决于账号角色与授权。
- Vite 构建仍有项目既有的单 chunk 大于 500 kB 警告，与本次字段修复无关。

## 失败尝试
- 受控浏览器隔离求值环境不暴露 `fetch/XMLHttpRequest`，无法直接读取接口响应体。
- 尝试在新标签直接打开已观察到的接口请求被浏览器安全策略拦截；未继续绕过。
- 改为通过官方前端源码、真实表格 DOM 和配置控件 `value` 交叉确认字段契约。
- 沙箱内首次运行 `tsx` 因 pnpm 依赖目录读取 `EPERM` 失败；改为获批后在沙箱外执行，测试正常通过。

## 已知限制
- 当前只展示详情接口返回的第一页商品数据，尚未实现商品子分页或全部商品自动拉取。
- 当前缓存仅为进程内 30 秒短期缓存，不做历史持久化。
- 未实现 Excel 导出和其他平台直播明细。
